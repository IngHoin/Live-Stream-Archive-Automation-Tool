개인정보 처리방침

최종 수정일: 2026년 4월 6일

Live Stream Archive Automation Tool (이하 '본 프로그램')은 사용자가 요청한 스트리밍 아카이브 영상을 사용자의 설정에 따라 업로드하는 기능을 제공하기 위해 최소한의 개인정보를 수집 및 활용합니다.

1. 수집하는 개인정보 및 API 스코프(Scopes)

본 프로그램은 이용자의 구글 계정 인증을 위해 Google OAuth 2.0을 활용하며, 다음의 API 권한을 사용자의 로컬 환경에서만 활용합니다.

  • Google 계정 정보: 기본 프로필 정보 및 이메일 주소
  • YouTube Data API v3 Scopes:
    • https://www.googleapis.com/auth/youtube.upload
    • https://www.googleapis.com/auth/youtube

2. 개인정보의 이용 목적 및 제3자 제공

수집된 정보는 오직 다음의 목적으로만 활용되며, 어떠한 경우에도 외부에 제공하거나 공유하지 않습니다.

  • 사용자의 요청에 따른 YouTube 동영상 업로드 자동화
  • 사용자 본인의 YouTube 채널 데이터 관리 및 설정

3. 데이터 보유, 삭제 및 보안

[데이터 삭제 안내]
사용자는 본 프로그램 내 제공되는 '데이터 삭제' 기능을 통해 로컬에 저장된 인증 정보 및 관련 데이터를 언제든지 즉시 삭제할 수 있습니다.
  • 데이터 활용 기간: 사용자가 본 프로그램을 사용하는 기간으로 명시합니다.
  • 쿠키 및 추적 기술: 본 프로그램은 쿠키를 활용하거나 사용자의 활동을 추적하지 않습니다.
  • 인증 데이터 암호화: 모든 인증 정보는 운영체제(OS) 환경에서 제공하는 보안 기술을 활용하여 암호화된 상태로 사용자의 로컬 시스템 내에만 저장됩니다.

4. 아동의 개인정보 보호

본 프로그램은 13세 미만의 아동으로부터 고의로 개인정보를 수집하지 않습니다. 만약 아동의 정보가 수집된 사실을 인지할 경우 즉시 해당 데이터를 삭제합니다.

5. 구글 API 정책 준수

본 프로그램이 Google API로부터 수신한 정보를 활용하는 경우, Google API 서비스 사용자 데이터 정책을 준수합니다.

Privacy Policy

Last Updated: April 6, 2026

Live Stream Archive Automation Tool (hereinafter referred to as the 'Program') collects and utilizes minimal personal information to provide the function of uploading streaming archive videos requested by the user.

1. Information We Collect & API Scopes

This Program utilizes Google OAuth 2.0 for user authentication and utilizes the following API permissions only within the user's local environment:

  • Google Account Info: Basic profile information and email address
  • YouTube Data API v3 Scopes:
    • https://www.googleapis.com/auth/youtube.upload
    • https://www.googleapis.com/auth/youtube

2. Purpose of Use & Third-Party Sharing

The collected information is utilized solely for the following purposes and is never provided to or shared with third parties.

  • Automating YouTube video uploads at the user's request
  • Managing the user's own YouTube channel data and settings

3. Data Retention, Deletion & Security

[Data Deletion Guide]
Users can immediately delete locally stored authentication information and related data at any time through the 'Data Deletion' function provided within the Program.
  • Data Usage Period: This is specified as the period during which the user utilizes this Program.
  • Cookies and Tracking: This Program does not utilize cookies or any tracking technologies.
  • Authentication Data Encryption: All authentication information is stored only within the user's local system in an encrypted state using OS-level security.

4. Children's Privacy

This Program does not knowingly collect personal information from children under the age of 13. If we become aware that such information has been collected, we will delete it immediately.

5. Compliance with Google API Policies

Any utilization of information received from Google APIs by this Program complies with the Google API Services User Data Policy.
