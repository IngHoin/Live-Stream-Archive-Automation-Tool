개인정보 처리방침

본 방침은 Live Stream Archive Automation Tool(이하 "본 도구")의 이용자와 관련하여 개인정보가 어떻게 처리되는지 설명합니다.

1. 수집하는 개인정보 항목

본 도구는 이용자의 구글 계정 인증을 위해 Google OAuth 2.0을 사용하며, 다음과 같은 정보를 사용자의 로컬 환경에서만 일시적으로 처리합니다.

  • Google 계정의 기본 프로필 정보 및 이메일 주소
  • YouTube 동영상 업로드 및 관리를 위한 API 접근 권한

2. 개인정보의 이용 목적

수집된 정보는 오직 다음의 목적으로만 사용됩니다.

  • 사용자의 요청에 따른 YouTube 동영상 업로드 자동화
  • 사용자 본인의 YouTube 채널 데이터 관리 및 설정

3. 개인정보의 공유 및 제공

본 도구는 사용자의 개인정보를 외부 서버에 저장하거나 제3자에게 공유하지 않습니다. 모든 데이터는 사용자의 로컬 컴퓨터 내에서만 처리됩니다.

4. 데이터 보안

본 도구는 시스템 보안 기술을 활용하여 인증 토큰 등을 안전하게 관리하며, 사용자가 로그아웃하거나 앱을 삭제할 경우 관련 데이터는 즉시 파기됩니다.

Privacy Policy

This policy explains how personal information is handled in relation to the users of the Live Stream Archive Automation Tool.

1. Information We Collect

This tool uses Google OAuth 2.0 for user authentication and processes the following information only within the user's local environment:

  • Basic Google profile information and email address
  • API access for uploading and managing YouTube videos

2. Purpose of Use

The collected information is used solely for the following purposes:

  • Automating YouTube video uploads at the user's request
  • Managing the user's own YouTube channel data and settings

3. Data Sharing and Disclosure

This tool does not store your personal information on external servers or share it with third parties. All data is processed locally on your computer.

4. Data Security

The tool manages authentication tokens securely using system protection technologies, and all related data is destroyed upon logout or deletion of the app.
