개인정보 처리방침

최종 수정일: 2026년 4월 6일

Live Stream Archive Automation Tool (이하 '본 프로그램')은 사용자가 요청한 스트리밍 아카이브 영상을 사용자의 설정에 따라 업로드하는 기능을 제공하기 위해 최소한의 개인정보를 수집 및 사용합니다.

본 프로그램은 클라이언트 사이드 앱으로, 사용자의 데이터를 별도의 외부 서버에 저장하거나 전송하지 않습니다.

1. 수집하는 개인정보 항목

본 프로그램은 이용자의 구글 계정 인증을 위해 Google OAuth 2.0을 사용하며, 다음과 같은 정보를 사용자의 로컬 환경에서만 일시적으로 처리합니다.

  • Google 계정의 기본 프로필 정보 및 이메일 주소
  • YouTube 동영상 업로드 및 관리를 위한 API 접근 권한

2. 개인정보의 이용 목적

수집된 정보는 오직 다음의 목적으로만 사용됩니다.

  • 사용자의 요청에 따른 YouTube 동영상 업로드 자동화
  • 사용자 본인의 YouTube 채널 데이터 관리 및 설정

3. 개인정보의 보유 및 삭제 절차

[데이터 삭제 안내]
사용자는 본 프로그램 내 제공되는 '데이터 삭제' 기능을 통해 로컬에 저장된 인증 정보 및 관련 데이터를 언제든지 즉시 삭제할 수 있습니다.
  • 인증 데이터 암호화: 모든 인증 정보는 운영체제(OS) 환경에서 제공하는 보안 기술을 활용하여 암호화된 상태로 사용자의 로컬 시스템 내에만 저장됩니다.
  • 저장된 데이터 삭제: 본 프로그램은 별도의 서버를 운영하지 않으므로 모든 데이터는 사용자 기기 내에서만 관리됩니다. 따라서 사용자가 프로그램 내 기능을 이용하거나 관련 로컬 데이터를 직접 삭제함으로써 정보를 즉시 삭제할 수 있습니다.
  • 데이터 활용 기간: 사용자가 본 프로그램을 사용하는 기간으로 명시합니다.

4. 구글 API 정책 준수 및 제3자 제공

본 프로그램은 수집된 정보를 외부에 제공하거나 공유하지 않습니다. 본 프로그램이 Google API로부터 수신한 정보를 사용하는 경우, Google API 서비스 사용자 데이터 정책을 준수합니다.

Privacy Policy

Last Updated: April 6, 2026

Live Stream Archive Automation Tool (hereinafter referred to as the 'Program') collects and uses minimal personal information to provide the function of uploading streaming archive videos requested by the user according to the user's settings.

This Program is a client-side app and does not store or transmit user data to any separate external servers.

1. Information We Collect

This Program uses Google OAuth 2.0 for user authentication and processes the following information only within the user's local environment:

  • Basic Google profile information and email address
  • API access for uploading and managing YouTube videos

2. Purpose of Use

The collected information is used solely for the following purposes:

  • Automating YouTube video uploads at the user's request
  • Managing the user's own YouTube channel data and settings

3. Data Retention and Deletion Procedures

[Data Deletion Guide]
Users can immediately delete locally stored authentication information and related data at any time through the 'Data Deletion' function provided within the Program.
  • Authentication Data Encryption: All authentication information is stored only within the user's local system in an encrypted state using security technologies provided by the operating system (OS) environment.
  • Deletion of Stored Data: Since this Program does not operate a separate server, all data is managed only within the user's device. Therefore, users can immediately delete information by using functions within the Program or by directly deleting related local data.
  • Data Usage Period: This is specified as the period during which the user uses this Program.

4. Compliance with Google API Policies and Third-Party Provision

This Program does not provide or share collected information with external parties. Any use of information received from Google APIs by this Program complies with the Google API Services User Data Policy.
