개인정보 처리방침

Live Stream Archive Automation Tool (이하 '본 프로그램')은(는) 사용자의 개인정보를 소중하게 생각하며, 관련 법령을 준수합니다.

1. 개인정보의 처리 목적

본 프로그램은 유튜브 API를 활용하여 사용자가 요청한 스트리밍 아카이브 영상을 자동으로 업로드하고 관리하는 기능을 제공하기 위해 최소한의 정보를 처리합니다.

2. 처리하는 개인정보 항목

  • 필수항목: Google 계정 식별 정보(이메일 주소), 유튜브 채널 접근 권한(업로드 및 관리).
  • 수집 방법: Google OAuth 2.0 인증 과정을 통해 사용자가 직접 승인한 범위 내에서만 접근합니다.

3. 개인정보의 보유 및 파기

본 프로그램은 클라이언트 사이드 애플리케이션으로, 원칙적으로 서버에 사용자의 개인정보를 저장하지 않습니다. 모든 인증 토큰(token.json)은 사용자의 로컬 컴퓨터에만 저장되며, 프로그램 삭제 시 함께 파기됩니다.

4. 제3자 제공 및 공유

본 프로그램은 수집된 정보를 외부에 제공하거나 공유하지 않습니다. 모든 데이터 처리는 Google API 서비스 정책을 준수하며, 오직 유튜브 업로드 목적으로만 사용됩니다.

Privacy Policy

This Privacy Policy describes how Live Stream Archive Automation Tool (the "Software") handles your personal information when you use our YouTube automation services.

1. Purpose of Data Processing

The Software uses the YouTube API to automatically archive and upload live stream recordings as requested by the user. We do not use your data for any other purposes.

2. Information We Access

  • Scopes used: .../auth/youtube.upload
  • Data accessed: Google account email address and YouTube channel management rights.
  • Method: Authorized through Google OAuth 2.0.

3. Data Storage and Security

The Software is a local client-side application. We do not store any user data on external servers. All authentication tokens (e.g., token.json) are stored strictly on your local machine and remain under your control.

4. Compliance with Google API Policy

Our use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
