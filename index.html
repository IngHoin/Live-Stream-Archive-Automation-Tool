개인정보 처리방침

Live Stream Archive Automation Tool (이하 '본 프로그램')은(는) 사용자의 개인정보를 소중하게 생각하며, 관련 법령을 준수합니다.

1. 개인정보의 처리 목적

본 프로그램은 유튜브 API를 활용하여 사용자가 요청한 스트리밍 아카이브 영상을 자동으로 업로드하고 관리하는 기능을 제공하기 위해 최소한의 정보를 처리합니다.

2. 처리하는 개인정보 항목

  • 필수항목: Google 계정 식별 정보(이메일 주소), 유튜브 채널 접근 권한.
  • 수집 방법: Google OAuth 2.0 인증 과정을 통해 사용자가 직접 승인한 범위 내에서만 접근합니다.

3. 개인정보의 보유 및 파기 절차

본 프로그램은 클라이언트 사이드 애플리케이션으로, 사용자의 데이터를 별도의 외부 서버에 저장하지 않습니다.

[데이터 파기 안내]
사용자는 본 프로그램 내 제공되는 '데이터 파기' 기능을 통해 로컬에 저장된 인증 정보 및 관련 데이터를 즉시 삭제할 수 있습니다.
  • 암호화 저장: 모든 인증 토큰(token.json)은 Windows DPAPI(Data Protection API)를 통해 암호화되어 사용자의 로컬 환경에만 저장됩니다.
  • 직접 파기: 본 프로그램은 서버 기반 서비스가 아니므로 자동 파기되지 않으며, 사용자가 프로그램 내 파기 기능을 이용하거나 관련 로컬 파일을 직접 삭제함으로써 데이터를 즉시 파기할 수 있습니다.

4. 구글 API 정책 준수 및 제3자 제공

본 프로그램은 수집된 정보를 외부에 제공하거나 공유하지 않습니다. 본 프로그램이 Google API로부터 수신한 정보를 사용하는 경우, Google API 서비스 사용자 데이터 정책을 준수합니다.

Privacy Policy

This Privacy Policy describes how Live Stream Archive Automation Tool (the "Software") handles your personal information.

1. Purpose of Data Processing

The Software uses the YouTube API to automatically archive and upload live stream recordings as requested by the user.

2. Information We Access

  • Scopes used: .../auth/youtube.upload
  • Data accessed: Google account email address and YouTube channel management rights.

3. Data Storage and Destruction

The Software is a local client-side application. We do not store any user data on external servers.

[Data Destruction Policy]
Users can permanently delete their authentication information and related data at any time through the 'Data Destruction' feature provided within the application.
  • Encryption: All authentication tokens (e.g., token.json) are stored on the user's local machine and encrypted using Windows DPAPI (Data Protection API).
  • Retention: Since the Software is not server-based, data is not automatically destroyed upon uninstallation. Users must use the in-app destruction feature or manually delete the local files to destroy the data.

4. Compliance with Google API Policy

Our use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
