Live Stream Archive Tool

스트리밍 아카이브를 유튜브에 자동으로 업로드하고 활용하는 창작자를 위한 스마트 자동화 솔루션입니다.

주요 특징

자동화 업로드

스트리밍 종료 후 업로드 과정을 설정 한 번으로 자동화합니다.

로컬 보안 환경

모든 데이터는 서버가 아닌 사용자 로컬 환경에서만 활용됩니다.

데이터 완전 제어

저장된 인증 정보를 언제든지 즉시 삭제하고 관리할 수 있습니다.

YouTube API 연동

공식 Google API 스코프를 준수하여 투명한 연동을 지원합니다.

상세 기능 사양

기본 기능

  • 유튜브 API를 활용한 동영상 업로드 기능
  • 로컬 영상 파일을 감지하여 업로드 리스트 생성
  • 업로드 진행 상황 실시간 확인
  • 업로드할 영상의 기본 정보 설정

추가 기능

  • 사용자 인증 정보 암호화 및 로컬 저장
  • 저장된 로컬 데이터 일괄 삭제 기능
  • 한국어 및 영어 다국어 지원
  • 사용자 환경에 맞춘 업로드 설정 커스터마이징
