Live Stream Archive Tool

스트리밍 아카이브를 유튜브에 자동으로 업로드하고 활용하는 창작자를 위한 스마트 자동화 솔루션입니다.

자동화 업로드

스트리밍 종료 후 업로드 과정을 설정 한 번으로 자동화합니다.

로컬 보안 환경

모든 데이터는 서버가 아닌 사용자 로컬 환경에서만 활용됩니다.

데이터 완전 제어

저장된 인증 정보를 언제든지 즉시 삭제하고 관리할 수 있습니다.

YouTube API 연동

공식 Google API 스코프를 준수하여 투명한 연동을 지원합니다.

기본 기능

  • 유튜브 API 연동 동영상 업로드
  • 로컬 영상 파일 자동 탐색 및 매칭
  • 업로드 상태 실시간 모니터링
  • 메타데이터(제목, 설명) 자동 설정

추가 기능

  • 데이터 암호화 및 로컬 보안 관리
  • 원클릭 로컬 인증 데이터 완전 삭제
  • 다국어 지원 (한국어/영어)
  • 사용자 맞춤형 업로드 스케줄링
